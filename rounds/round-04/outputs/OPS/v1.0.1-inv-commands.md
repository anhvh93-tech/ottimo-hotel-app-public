# OTTIMO v1.0.1 (đợt 1, tin Google Chat): các lệnh anh/chị tự chạy

Dành cho: Chủ đầu tư · Soạn: OPS · 01/11/2026 · Round 4, bước Sản xuất · Kế hoạch: `rounds/round-04/plan-v1.0.1.md` (T1, T12)
Tài liệu kỹ thuật đi kèm (cho đội): `product/infra/server/README.md` mục 13.

Lần này đội **không** vào máy chủ. Anh/chị tự chạy lệnh trên máy Mac của mình. Có 2 phần, làm vào 2 lúc khác nhau:

| Phần | Khi nào làm | Mất bao lâu |
|---|---|---|
| **A. Staging** (bản thử) | Khi đội nhắn "PR #16 đã gộp". Làm **trước** khi bấm duyệt "deploy staging" trên GitHub | khoảng 15 phút |
| **B. Production** (bản chính thức) | Khi đội nhắn "tag v1.0.1 sẵn sàng". Làm **trước** khi bấm duyệt Release trên GitHub | khoảng 25 phút (gồm bước dán webhook) |

---

## Luật chung – đọc một lần

1. Mỗi bước là **một khối lệnh**. Bấm vào khối, chọn hết, sao chép (⌘C), dán vào Terminal (⌘V), rồi nhấn **Enter**. Chép **cả khối**, kể cả khi khối dài. Không sửa gì bên trong, trừ chỗ tài liệu bảo thay.
2. So kết quả với mục **"Đúng là"** của bước đó. Đúng thì làm bước tiếp theo. **Khác** thì dừng lại, chụp màn hình Terminal và gửi đội. (Ở bước dán webhook, đừng chụp màn hình: xem bước B8.)
3. Máy hỏi `password` hoặc `[sudo] password for ottimo-admin` thì gõ **mật khẩu của tài khoản `ottimo-admin`** (không hiện chữ khi gõ), rồi nhấn Enter. Đừng gửi mật khẩu này cho ai.
4. Lần đầu nối tới `desk.ottimo.vn`, máy có thể hỏi `Are you sure you want to continue connecting (yes/no/[fingerprint])?`. Đây vẫn là máy chủ Nhân Hòa đang chạy staging, nên gõ `yes` rồi Enter. Nếu thấy chữ **`WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED`** thì **dừng**, báo đội, không làm tiếp.
5. Không lệnh nào trong tài liệu này in ra mật khẩu, khóa hay URL webhook. Thấy chuỗi dài lạ thì cũng đừng gửi lên chat; chỉ gửi ảnh chụp cho đội qua kênh riêng.
6. Gõ nhầm, hoặc Terminal "treo": nhấn **Ctrl + C** rồi chạy lại đúng bước đó. Mọi bước đều chạy lại được.

## Phần A – Staging (bản thử)

Mục đích: đưa bộ cấu hình máy chủ mới lên, rồi tạo tệp bí mật webhook để trống. Có tệp này thì lượt "deploy staging" của bản Google Chat không bị máy chủ từ chối. Tệp trống nghĩa là Chat ở staging đang **tắt**. Đây là trạng thái đúng ở đợt này.

### A1. Lấy bản mới nhất của dự án về Mac

```bash
cd ~/Desktop/hotel-app && git fetch origin && git log -1 --format='%h %s' origin/main
```
**Đúng là:** in ra một dòng gồm một mã ngắn (khoảng 8 ký tự) và một câu. Mã này phải **trùng mã đội nhắn** khi báo "PR #16 đã gộp".

### A2. Đóng gói cấu hình máy chủ

```bash
cd ~/Desktop/hotel-app && rm -f /tmp/ottimo-infra.tgz && git archive --format=tar.gz -o /tmp/ottimo-infra.tgz origin/main product/infra && ls -lh /tmp/ottimo-infra.tgz
```
**Đúng là:** một dòng kết thúc bằng `/tmp/ottimo-infra.tgz`, dung lượng khoảng 100–300K.

### A3. Gửi gói lên máy chủ

```bash
scp -i ~/.ssh/ottimo_ops /tmp/ottimo-infra.tgz ottimo-admin@desk.ottimo.vn:ottimo-infra.tgz
```
**Đúng là:** một dòng `ottimo-infra.tgz   100% …`.

### A4. Mở gói trên máy chủ

```bash
ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'cd / && rm -rf ~/ottimo-bundle && mkdir -m 700 ~/ottimo-bundle && tar -xzf ~/ottimo-infra.tgz -C ~/ottimo-bundle && grep -c set-booking-chat ~/ottimo-bundle/product/infra/server/bin/init-secrets.sh'
```
**Đúng là:** in ra **một con số từ 3 trở lên**, rồi `Connection to desk.ottimo.vn closed.` Nếu ra `0` thì gói chưa có bản Google Chat: báo đội.

### A5. Thay cấu hình staging (có giữ bản cũ để quay lui)

```bash
ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'cd / && set -e && B=/root/ottimo-staging-bundles/infra-$(date +%Y%m%d-%H%M%S) && sudo mkdir -p /root/ottimo-staging-bundles && sudo cp -a /opt/ottimo/infra "$B" && sudo rsync -a --delete --delete-excluded --chown=root:root --exclude .DS_Store --exclude .out --exclude .work --exclude .env --exclude ".env.*" --exclude server/test/ ~/ottimo-bundle/product/infra/ /opt/ottimo/infra/ && sudo chmod -R go-w /opt/ottimo/infra && sudo chmod 0755 /opt/ottimo/infra/server/bin/* /opt/ottimo/infra/postgres/init/02-roles.sh && echo "BAN CU GIU O: $B" && sudo diff -rq --exclude=test ~/ottimo-bundle/product/infra /opt/ottimo/infra && echo "STAGING: CAU HINH MOI DA VAO"'
```
**Đúng là:** 2 dòng
```
BAN CU GIU O: /root/ottimo-staging-bundles/infra-2026…
STAGING: CAU HINH MOI DA VAO
```
Bước này **không** dừng hay khởi động lại gì: app staging vẫn chạy như cũ.

### A6. Tạo tệp bí mật còn thiếu (webhook để trống)

```bash
ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'cd / && sudo /opt/ottimo/infra/server/bin/init-secrets.sh'
```
**Đúng là:** dòng đầu tiên là
```
init-secrets: created booking_request_chat_webhook in /opt/ottimo/secrets
```
Sau dòng đó là một khối chữ tiếng Anh bắt đầu bằng `Next:`. Khối này chỉ là ghi chú cho đội, anh/chị **bỏ qua**. Lệnh không in mật khẩu hay khóa nào.
- Nếu dòng đầu là `init-secrets: nothing to do – all files exist` thì tệp đã có từ trước, vẫn đúng.
- Nếu dòng đầu ghi thêm tên khác ngoài `booking_request_chat_webhook` thì vẫn được với staging, nhưng chụp màn hình gửi đội.

### A7. Kiểm tệp vừa tạo và cấu hình

```bash
ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'cd / && sudo stat -c "%n uid=%u mode=%a size=%s" /opt/ottimo/secrets/booking_request_chat_webhook && sudo -u ottimo /opt/ottimo/infra/server/bin/dc --profile deploy config -q && echo "CAU HINH: OK"'
```
**Đúng là:**
```
/opt/ottimo/secrets/booking_request_chat_webhook uid=1000 mode=400 size=0
CAU HINH: OK
```

### A8. Kiểm bản sửa "chạy từ thư mục bất kỳ" (ARC yêu cầu)

Lệnh này **cố ý không có `cd /`**.
```bash
ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'sudo -u ottimo /opt/ottimo/infra/server/bin/ops-check.sh containers http5xx'
```
**Đúng là:** 2 dòng bắt đầu bằng `ok`:
```
ok   containers: postgres api worker web running, api healthy
ok   http5xx: 0 server errors (5xx) in 35 min
```
(con số có thể khác 0, miễn là dòng bắt đầu bằng `ok`).

### A9. (Chỉ khi anh/chị đã tạo **phòng Chat thử** theo ESC-046) Dán webhook phòng thử

Chưa có phòng thử thì **bỏ qua bước này**: Chat ở staging cứ để tắt.
**Tuyệt đối không** dán webhook của phòng thật "OTTIMO – Yêu cầu đặt phòng" vào staging.
Cách làm giống bước B8 bên dưới. Chỉ khác ở lệnh (đường dẫn `/opt/ottimo/`, không có `-prod`):
```bash
ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'cd / && sudo /opt/ottimo/infra/server/bin/init-secrets.sh --set-booking-chat'
```

### A10. Duyệt deploy staging trên GitHub

1. GitHub → repo → **Actions** → mở lượt chạy mới nhất của `main` (lượt có PR #16).
2. Bấm **Review deployments**, tích **staging**, bấm **Approve and deploy**.
3. Đợi tới khi job `deploy staging` có dấu tích xanh, thường 5–10 phút.

### A11. Kiểm Chat ở staging sau deploy

```bash
ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'cd / && sudo -u ottimo /opt/ottimo/infra/server/bin/dc logs --no-color --no-log-prefix worker | grep "\"msg\":\"chat" | tail -3'
```
**Đúng là** (nếu không làm A9):
```
{"level":"info","msg":"chat: off","reason":"NOT_CONFIGURED"}
{"level":"A","msg":"chat detail level"}
```
Nếu đã làm A9 thì dòng đầu là `{"level":"info","msg":"chat: on"}`.
Nếu **không in gì** thì gửi ảnh chụp cho đội. Nguyên nhân thường gặp: lỡ bấm duyệt ở A10 **trước** khi làm xong A5–A7. Cách sửa: chạy lệnh dưới đây, rồi chạy lại A11.
```bash
ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'cd / && sudo -u ottimo /opt/ottimo/infra/server/bin/dc up -d --no-deps worker'
```

Xong phần A: nhắn đội **"Đã xong phần A staging"**, kèm ảnh chụp kết quả A7 và A11.

## Phần B – Production (bản chính thức, đợt 1)

Mục đích:
- sao lưu trước khi làm;
- đưa bộ cấu hình mới lên production;
- tạo tệp webhook;

### B8. Dán URL webhook của phòng "OTTIMO – Yêu cầu đặt phòng"

**Lấy URL** (trên Google Chat, máy tính):
1. Mở phòng **OTTIMO – Yêu cầu đặt phòng**.
2. Bấm tên phòng ở trên cùng → **Apps & integrations** (Ứng dụng và tích hợp) → **Webhooks** → **Add webhook**.
3. Tên: `Desk OTTIMO`. Ảnh đại diện: để trống. Bấm **Save**.
4. Bấm biểu tượng sao chép cạnh webhook vừa tạo. URL bắt đầu bằng `https://chat.googleapis.com/v1/spaces/`.

**Không** dán URL này vào Zalo, email, ghi chú hay tin nhắn cho đội. Chỉ dán vào Terminal ở bước dưới.

**Dán lên máy chủ:**
```bash
ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'cd / && sudo /opt/ottimo-prod/infra/server/bin/init-secrets.sh --set-booking-chat'
```
1. Máy in vài dòng tiếng Anh, rồi dừng ở `Webhook URL:`.
2. Bấm ⌘V để dán. **Màn hình không hiện gì**, như khi gõ mật khẩu. Nhấn **Enter** một lần.

**Đúng là:** 3 dòng cuối
```
checked: bash rule only (image tool not available)
chat webhook: set (<một con số, khoảng 150–200> chars)
Now: /opt/ottimo-prod/infra/server/bin/dc restart worker   – then check the log line 'chat: on' (or 'chat: off').
```
- Dòng `checked: bash rule only` là bình thường: bản đang chạy chưa phải v1.0.1.
- Dòng `Now: … restart worker`: **chưa cần làm**. Bước B10 (Release) sẽ tự khởi động lại worker.
- Nếu ra `URL không hợp lệ (invalid URL) – nothing written.` thì URL chép chưa đủ hoặc thừa. Chép lại ở mục 4 rồi chạy lại bước này.
- Nếu lỡ nhấn Enter mà chưa dán, máy sẽ in `chat webhook: empty (Chat off)`. Không sao: chạy lại bước này.
- Bước này **không chụp màn hình gửi đi** (màn hình không có URL, nhưng để chắc chắn). Chỉ nhắn đội con số `set (… chars)`.

Kiểm tệp sau khi dán:
```bash
ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'cd / && sudo stat -c "%n uid=%u mode=%a size=%s" /opt/ottimo-prod/secrets/booking_request_chat_webhook'
```
**Đúng là:** `uid=1000 mode=400 size=<cùng con số ở trên>`.

### B9. Kiểm trang ottimo.vn với bộ kiểm mới (không đổi gì)

```bash
ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'cd / && sudo -u ottimo bash -c "/opt/ottimo-prod/infra/server/bin/deploy-landing.sh \$(cat /opt/ottimo-prod/state/landing_tag) --check-only" 2>&1 | tail -4'
```
**Đúng là:** trong mấy dòng in ra có
- `en 2026-10-24 (same bytes as published)`;
- `vi 2026-10-24 (same bytes as published)`;
- dòng cuối có `CHECK ONLY: … nothing switched or recorded`.

Có chữ `FAIL` thì gửi ảnh chụp cho đội. Bước này không chặn Release.

### B10. Duyệt Release v1.0.1 trên GitHub

1. GitHub → repo → **Actions** → lượt chạy **Release** của tag `v1.0.1`.
2. Bấm **Review deployments**, tích **production**, bấm **Approve and deploy**.
3. Đợi job deploy có dấu tích xanh, thường 5–10 phút. Desk có thể chập chờn khoảng 15–30 giây lúc đổi bản.

Job báo đỏ `failed (step=…)`: máy chủ đã **tự trả về bản cũ**, Desk vẫn chạy. Chụp dòng đó gửi đội. Đừng bấm chạy lại.

### B14. Gửi thử một yêu cầu và kiểm K1 (khoảng 10 phút, làm ngay sau B13)

1. Ghi lại **giờ hiện tại**, ví dụ 09:40.
2. Trên ottimo.vn, điền form "Yêu cầu đặt phòng":
   - tên **đúng** `TEST OTTIMO`;
   - kênh **Email**, địa chỉ `info@ottimo.vn`;
   - **không** điền số điện thoại;
   - nếu trình duyệt tự điền thì xóa phần tự điền.
   Gửi, rồi chép **mã `REQ-…`** ở trang cảm ơn.

## Mỗi sáng (cho tới khi đội báo đã có kiểm tự động): Chat có bị "im" không?

```bash
ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'cd / && sudo -u ottimo /opt/ottimo-prod/infra/server/bin/dc logs --no-color --no-log-prefix --since 24h worker | grep -c "\"msg\":\"chat dead\""'
```
**Đúng là:** `0`. Số lớn hơn 0 nghĩa là có tin không tới được phòng Chat, ví dụ webhook đã bị xóa. Khi đó yêu cầu vẫn nằm trên Desk (H03), anh/chị xem ở đó và báo đội.

## Khi cần tắt Chat ngay (ví dụ lỡ để lộ URL)

1. Trong Google Chat, xóa webhook "Desk OTTIMO" của phòng: phòng → Apps & integrations → Webhooks → xóa.
2. Chạy B8 nhưng ở dấu nhắc `Webhook URL:` **chỉ nhấn Enter** (không dán gì). Kết quả: `chat webhook: empty (Chat off)`.
3. Khởi động lại worker:
   ```bash
   ssh -t -i ~/.ssh/ottimo_ops ottimo-admin@desk.ottimo.vn 'cd / && sudo -u ottimo /opt/ottimo-prod/infra/server/bin/dc restart worker'
   ```
4. Muốn bật lại: tạo webhook mới rồi làm lại B8 và bước 3 ở trên.
