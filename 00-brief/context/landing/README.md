# Tư liệu cho landing page ottimo.vn

Chủ đầu tư chép vào thư mục `raw/` (không đưa lên GitHub – file gốc nặng):
- ảnh căn hộ, khu chung, view, quanh khu (càng gốc càng tốt, JPG/PNG/HEIC);
- e-brochure (ví dụ `OTTIMO_Ebrochure_16x9_Terracotta_C1_SlowLiving.pdf`);
- logo (nếu có bản vector: SVG/AI/PDF).

UXD chọn và tối ưu ảnh (WebP/AVIF, nhiều cỡ) vào `product/apps/landing-web/` – chỉ bản đã tối ưu mới vào git.
