# Tài liệu bối cảnh bổ sung

Đặt vào thư mục này mọi tài liệu giúp đội hiểu OTTIMO nhanh hơn. Điều phối viên và mọi vai sẽ đọc thư mục này ở đầu Round 1.

## Cần bổ sung
1. `financial-model.md` – tóm tắt cuộc trò chuyện **"Mô hình tài chính cho thuê phòng"**
2. `ottimo-project.md` – tóm tắt project **"OTTIMO BOUTIQUE STAY"** trên Claude (kèm các file knowledge của project nếu có: hợp đồng mẫu, bảng giá, nội quy, SOP…)

## Cách lấy nhanh
Mở một cuộc trò chuyện mới **bên trong project OTTIMO BOUTIQUE STAY** trên Claude và dán đoạn sau:

```
Hãy viết một file "ottimo-project.md" tổng hợp toàn bộ kiến thức của project này cho một đội phát triển phần mềm sắp build app quản lý vận hành cho OTTIMO. Gồm: thông tin cơ sở (địa chỉ, số căn, loại căn), giá và chính sách (ngắn ngày, dài hạn, cọc, hủy, phụ thu, phí phạt), mô hình tài chính (chi phí thuê, chi phí vận hành, doanh thu mục tiêu, điểm hòa vốn), quy trình vận hành (lễ tân, dọn phòng, bảo trì, khai báo lưu trú), nhân sự và vai trò, kênh bán, các vấn đề đang gặp. Tìm trong mọi cuộc trò chuyện của project, kể cả cuộc "Mô hình tài chính cho thuê phòng". Giữ đúng số liệu, ghi rõ chỗ nào chưa chốt.
```

Lưu kết quả thành file `.md` và bỏ vào thư mục này (hoặc dán vào Claude Code và bảo: "lưu vào 00-brief/context/ottimo-project.md").
